# Результаты экспериментов

Тестовая выборка: 500 изображений, по 5 изображений каждого из 100 классов. Для обучения использовано максимум 80 изображений каждого класса; в аугментированном запуске добавлено по одному преобразованному примеру на каждый обучающий пример.

| Данные | Модель | Accuracy | Macro F1 | Обучающих примеров |
|---|---|---:|---:|---:|
| Исходные | Logistic Regression | 0.390 | 0.380 | 8000 |
| Исходные | Random Forest | 0.360 | 0.336 | 8000 |
| Исходные | SVM | **0.438** | **0.431** | 8000 |
| Аугментированные | Logistic Regression | 0.374 | 0.369 | 16000 |
| Аугментированные | Random Forest | 0.398 | 0.372 | 16000 |
| Аугментированные | SVM | **0.472** | **0.469** | 16000 |

Вывод: в данном эксперименте аугментация повысила качество SVM с 0.438 до 0.472 (+3.4 процентных пункта), а Random Forest — с 0.360 до 0.398. Для Logistic Regression качество немного снизилось. Лучшей моделью оказалась SVM на аугментированных данных.

Запуски воспроизводятся командой:

```powershell
$env:PYTHONPATH="$PWD/vendor"
python -m src.pipeline --config configs/config.yaml --output-root .
```

Для базового эксперимента установите в конфигурации `use_augmentation: false`; для эксперимента с аугментацией — `true`.
